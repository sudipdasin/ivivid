# iVivid development roadmap

## 0.2 beta preview
- C++17/Qt 6 GUI and CMake build
- Config validation and first-write backup
- Light, Balanced and Max scaling presets
- Video color controls, debanding, safe hardware decode
- Audio tone controls and optional normalization
- Basic unit tests

## Next: 0.3
- Preserve arbitrary user mpv configuration via dedicated include/profile
- Detect Intel/AMD/other GPUs and available mpv capabilities
- Preview effective settings and warn on incompatible options
- Per-display and per-resolution profiles
- Accessibility, keyboard navigation, translations

## Later
- Shader library with licensing checks and integrity validation
- Performance telemetry (opt-in, local-only), dropped-frame monitoring
- Side-by-side A/B video comparison with reproducible test clips
- Package builds for Debian/Fedora/Arch and Flatpak
- CI matrix and reproducible quality/performance benchmarks

No roadmap item is a promise of a completed feature.
